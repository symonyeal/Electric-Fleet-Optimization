# Results

Regenerated by `python run_bench.py` from the bundles in this directory. A bundle is admitted only if it passes the schema check of `bench/schema.py` for its case (clean code revision, current formulation, unchanged inputs and scenario, a self-consistent result record, unchanged routes or schedule), or, for a bundle written before that schema, if [MIGRATION.json](MIGRATION.json) retains it. Every upper bound U is recomputed here by the independent replay; a replayed route set certifies its own length whoever produced it, so U may come from any route file that replays. A lower bound L counts only from an admitted bundle. Bundles that are not admitted are listed at the end with the reason.

Status fields follow the result contract of [Algorithms](../ALGORITHMS.md) §8: `solver_status` is the solver's own termination, `validation_status` whether the replay accepted the returned solution, `certificate_status` whether U and L agree within tolerance; the public `status` is `optimal` only when certified.
